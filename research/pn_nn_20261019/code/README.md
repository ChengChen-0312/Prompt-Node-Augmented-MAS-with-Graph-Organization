# Selected implementation snapshots

The 19 `.py.txt` files preserve the source already selected for reviewer inspection.
They are not a complete runnable experiment package. External imports, datasets,
execution adapters, original replies, model installations, and gateway bindings
remain dependencies; see `../protocol/REPRODUCTION_SCOPE.md`.

The files were copied byte for byte from the sanitized reviewer artifacts. Their
original internal labels remain unchanged. The release's offline commands execute
only the scripts in `statistics/`, never these snapshots.
